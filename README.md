Генератор случайных предложений

Это маленький Python-скрипт, который просто берет слова из списков и собирает из них случайные предложения. Ничего сложного — чисто для практики и фана 

Как это работает

Есть несколько списков слов:

кто (Программист, Кот и т.д.)
какой (быстрый, ленивый...)
что делает (пишет, создает...)
с чем (код, проект...)

Программа случайно выбирает по одному слову из каждого списка и собирает предложение.

Получается что-то вроде:

Кот ленивый пишет код.
Студент веселый анализирует сложную задачу.
Алгоритм загадочный взламывает базу данных.

Иногда звучит странно — но в этом и смысл 

Как запустить

Если у тебя уже установлен Python:

Скачай файл
Открой терминал в папке с ним
Запусти:
python main.py

И всё — увидишь 5 случайных предложений.
